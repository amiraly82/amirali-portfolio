# وب‌سایت پرتفولیو امیرعلی ایزی (Amirali Easy Portfolio)

وب‌سایت تعاملی، چندرسانه‌ای و دو‌زبانه (فارسی / انگلیسی) پرتفولیو شخصی طراح گرافیک و آرت دایرکتور **امیرعلی ایزی (AMIRALI EASY)**.

---

## 🚀 راهنمای راه‌اندازی روی سیستم جدید

برای اجرای این پروژه روی هر کامپیوتر دیگر (مک، ویندوز یا لینوکس) و ادامه کار با **Antigravity**:

### ۱. پیش‌نیازها
* نصب **Node.js** (نسخه ۱۸ یا بالاتر) از [nodejs.org](https://nodejs.org)
* نرم‌افزار **Google Antigravity**

### ۲. انتقال پروژه
کافی است کل پوشه پروژه (`سایت پرتفولیو`) را از طریق فلش‌مموری، فایل زیپ یا گیت به سیستم جدید منتقل کرده و در Antigravity با گزینه **Open Folder** باز کنید.

### ۳. اجرای سرور توسعه (Local Server)
ترمینال را در محیط Antigravity یا سیستم باز کرده و دستور زیر را اجرا کنید:

```bash
node server.js
```

سرور روی پورت ۸۰۰۰ بالا می‌آید:
* **صفحه اصلی:** `http://localhost:8000/`
* **آرشیو گالری آثار:** `http://localhost:8000/works.html`
* **صفحه جزئیات پروژه:** `http://localhost:8000/project.html?id=solaris`
* **پنل مدیریت اختصاصی:** `http://localhost:8000/admin.html`

> **نکته:** `server.js` از ماژول‌های داخلی Node.js (`http`, `fs`, `path`) استفاده می‌کند و نیازی به اجرای `npm install` ندارد.

## 📂 ساختار فایل‌ها و معماری پروژه

| نام فایل | نقش و کاربرد |
| :--- | :--- |
| `index.html` | صفحه اصلی با اسکرولی‌تلینگ فریم‌به‌فریم (هیرو، شیلد، مهارت‌ها، آثار برگزیده، فرم تماس) |
| `works.html` | صفحه آرشیو کامل آثار و فیلتربندی دسته‌ها |
| `project.html` | صفحه جزئیات هر پروژه (هیرو دو ستونه مدرن با تصویر بزرگ بدون قاب، متادیتا و گالری لایت‌باکس) |
| `admin.html` | پنل مدیریت برای افزودن/ویرایش پروژه‌ها، آپلود تصاویر و تنظیم متون |
| `server.js` | سرور بک‌اند برای آپلود تصاویر و ذخیره دیتا در `projects_data.json` و `site_texts.json` |
| `audio_player.js` | موتور پخش موزیک پس‌زمینه با حفظ موقعیت آهنگ در جابه‌جایی صفحات و صفحه ورودی |
| `bonfire.js` | سیستم تعاملی بون‌فایر سولز‌لایک (Bonfire Rest, Kindle Flame, Fast Travel) |
| `main.js` | منطق انیمیشن‌های اسکرولی، کانواس‌ها و تعاملات صفحه اصلی |
| `site_loader.js` | اعمال تنظیمات داینامیک متون، فونت‌ها و رنگ‌ها از سرور |
| `translations.js` | دیکشنری دو زبانه متون (فارسی و انگلیسی) |
| `projects_data.js` | دیتابیس پروژه‌ها و تصاویر آپلودشده |
| `skills_data.js` | لیست و جزئیات نرم‌افزارها و مهارت‌های تخصصی |
| `style.css` | شیوه استایل‌دهی کل سایت (شامل حالت‌های RTL و LTR و ریسپانسیو) |
| `Motoi Sakuraba - Knight Artorias.mp3` | قطعه موسیقی پس‌زمینه سایت (با لینک سمبلیک `bg-music.mp3`) |

## 🎨 اصول طراحی و قواعد پروژه (Design Guidelines)
1. **لوگوی برند:** کلمه **AMIRALI EASY** یک هویت تایپوگرافی انگلیسی لاتین است و در هر دو زبان فارسی و انگلیسی باید ثابت و بدون تغییر بماند.
2. **تصویر شاخص در صفحه پروژه:** تصویر در هیرو بالای صفحه بدون هیچ قاب، کادر یا نوشته‌ای نمایش داده می‌شود و کلیک روی آن لایت‌باکس تمام‌صفحه را باز می‌کند.
3. **جهت زبان‌ها:**
   * زبان فارسی: کاملاً راست‌چین (`direction: rtl`) با فونت‌های فارسی معین
   * زبان انگلیسی: کاملاً چپ‌چین (`direction: ltr`)
4. **تداوم صدا:** وضعیت و ثانیه جاری پخش موزیک در `sessionStorage` بین صفحات حفظ می‌شود.
